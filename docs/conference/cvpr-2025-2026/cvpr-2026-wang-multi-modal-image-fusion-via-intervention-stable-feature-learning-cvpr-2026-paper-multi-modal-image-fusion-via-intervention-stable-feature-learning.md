## Abstract
Multi-modal image fusion integrates complementary information from different modalities into a unified representation. Current methods predominantly optimize statistical correlations between modalities, often capturing dataset-induced spurious associations that degrade under distribution shifts. In this paper, we propose an intervention-based framework inspired by causal principles to identify robust cross-modal dependencies. Drawing insights from Pearl's causal hierarchy, we design three principled intervention strategies to probe different aspects of modal relationships: i) complementary masking with spatially disjoint perturbations tests whether modalities can genuinely compensate for each other's missing information, ii) random masking of identical regions identifies feature subsets that remain informative under partial observability, and iii) modality dropout evaluates the irreplaceable contribution of each modality. Based on these interventions, we introduce a Causal Feature Integrator (CFI) that learns to identify and prioritize intervention-stable features maintaining importance across different perturbation patterns through adaptive invariance gating, thereby capturing robust modal dependencies rather than spurious correlations. Extensive experiments demonstrate that our method achieves SOTA performance on both public benchmarks and downstream high-level vision tasks. The Code can be available.

- **任务定位**：多模态图像融合（MMIF），以红外–可见光图像融合（IVIF）为主要实例。

---

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：MMIF 旨在将不同模态的互补信息整合为比单模态更具信息量与鲁棒性的统一表示，广泛用于安防监控、自动驾驶、医学影像等。现有深度方法（CNN 双流、Transformer 全局注意力、扩散模型、对抗训练等）普遍把融合建模为**最大化模态间统计相关性**的优化问题，通过强度、梯度、语义等损失拟合源图像。
- **核心问题**：这类方法属于**纯观测式（observational）学习**，无法区分"真正的模态互补"与"数据集诱导的虚假关联（spurious correlation）"。当训练集中热特征与特定可见光模式高频共现时，模型会依据共现频率而非实际贡献来选择特征，导致在分布偏移（如恶劣天气、跨传感器）下性能脆弱。
- **理论切入点**：借鉴 Pearl 因果层级——关联（观察）、干预（操纵变量）、反事实（想象替代）——指出当前 MMIF 方法仅停留在"关联"层。作者的核心假设是：**对融合真正重要的特征应在不同干预模式下保持重要性（intervention-stable），而虚假关联会在系统扰动下瓦解**。
- **落地难点**：融合任务缺乏对特征保留的显式监督，且模态互补性常违反常规独立性假设，因此不能直接套用标准因果学习范式，需要为融合场景专门设计干预。
- **整体含义**：将融合从"被动拟合相关性"推进到"主动探测模态依赖"，以提升鲁棒性、泛化性与可解释性。

---

## 二、方法论

### 1. 核心思想
- 通过**结构化扰动（掩码操作 M）**系统探测模态关系，识别在不同扰动下仍保持重要性的"干预稳定特征"，据此引导网络优先学习稳健跨模态依赖、抑制虚假关联。

### 2. 三种原则化干预策略
- **干预一：互补掩码（测试跨模态补偿）**：生成空间互不重叠的掩码 $M_v, M_i$（$M_v \cap M_i = \emptyset$），分别遮挡两个模态的不同区域，得到 $I_{cf}=F(I_{ir}\odot M_i,\ I_{vi}\odot M_v)$。若模型仍能重建场景，说明存在真正的跨模态功能替代，而非模态内记忆。
- **干预二：随机掩码（识别局部充分特征）**：对两模态施加**相同**的随机掩码 $M_r$，得到 $I_{rf}=F(I_{ir}\odot M_r,\ I_{vi}\odot M_r)$，用于找出在部分可观测下仍具信息量的稳健局部依赖。
- **干预三：模态丢弃（量化模态必要性）**：完全移除单一模态，$I_{if}=F(I_{ir}\odot O, I_{vi})$、$I_{vf}=F(I_{ir}, I_{vi}\odot O)$，通过性能退化幅度衡量各模态不可替代的贡献，防止过度依赖单模态"捷径"。
- 三者协同：互补掩码保证真实跨模态交互，随机掩码识别稳健局部模式，模态丢弃避免退化解。

### 3. 网络结构与 CFI（Causal Feature Integrator）
- **整体架构**：U-Net 式孪生（Siamese）网络，两个**权重共享**编码器各含 3 个卷积块，逐级下采样得到多尺度特征 $\{\Theta^k_v\},\{\Theta^k_i\}$（k=1,2,3）；解码器逐级上采样并融合 CFI 输出。
- **CFI 三步骤**：
  1. **双向跨模态注意力**：由 1×1 卷积生成 Q/K/V；为控制计算量，将 K、V 池化为 $r\times r$（$r \ll H,W$，实验中 r=8），保留空间连续性、全局感受野与高分辨率可扩展性；计算 $\Theta^{v\to i}_k$ 与 $\Theta^{i\to v}_k$。
  2. **特征聚合**：互补特征 $\Theta^c_k=\Theta^{v\to i}_k+\Theta^{i\to v}_k$，局部特征 $\Theta^l_k=\Theta^i_k+\Theta^v_k$。
  3. **可学习不变性门控**：$\Theta^{CFI}_k = G_k\odot\Theta^c_k + (1-G_k)\odot\Theta^l_k$，其中 $G_k=\sigma(\mathrm{Conv}_{3\times3}(\Theta^c_k))$。门值高表示该区域在不同干预下保持信息（稳定特征），门值低表示干预敏感区（潜在虚假关联）。
- 与常规注意力按"统计显著性"加权不同，CFI 显式建模**跨扰动模式的重要性一致性**。

### 4. 训练目标
总损失 $L = L_f + \alpha L_{inv} + \beta L_{nec}$（$\alpha=0.1,\ \beta=0.05$）：
- **融合保真损失 $L_f$**：$\|I_f-I_{vi}\|_1 + \|I_f-I_{ir}\|_1 + \lambda_1\|\nabla I_f - \max(\nabla I_{vi},\nabla I_{ir})\|_1$（Laplacian 算子，$\lambda_1=1.0$）。
- **干预一致性损失 $L_{inv}$**：对 $I_{cf}, I_{rf}$ 惩罚门选稳定区域内的输出差异，并加正则项 $R(\bar G)=\|\mu(\bar G-\eta)\|_1 - H(\bar G)$（$\eta=0.3$，熵项促进类二值决策，防止退化），$\bar G$ 为三个尺度门控均值。
- **模态必要性损失 $L_{nec}$**：$\|I_f-I_{if}\|_1+\|I_f-I_{vf}\|_1$，迫使单模态输出与完整融合差异显著，抑制偏置。
- 训练时同时输出四路干预结果并施加约束。

## 三、实验设计

### 1. 数据集与 Benchmark
- **训练/验证**：MSRS 作训练集，RoadScene 作验证集；图像裁剪为 256×256 patch，随机增强，batch size 16。
- **IVIF 测试 benchmark（3 个）**：MSRS、TNO、M³FD。
- **医学图像融合（MIF，跨域泛化）**：Harvard 医学数据集（20 对 MRI-PET/SPECT），**直接用 IVIF 训练模型零样本迁移、不微调**。
- **下游高层视觉任务**：
  - 目标检测：M³FD 按 6:2:2 划分，YOLOv5 作检测器，报告 mAP 与类级 AP。
  - 语义分割：MSRS，使用官方分割网络，报告 6 类 IoU 与 mIoU。

### 2. 对比方法（9 个 SOTA）
TIMFusion、Conti、SAGE、MUFusion、LUT-Fuse、LRRNet、IGNet、DCEvo、A²RNet。

### 3. 评价指标
PSNR、SF、AG、CC、Qabf（均为越高越好）。

### 4. 主要实验组
- IVIF 定性/定量对比（三 benchmark）。
- 消融：w/o CFI、w/o $L_{inv}$、w/o $L_{nec}$、w/o $L_{nec}$&$L_{inv}$、w/o Int（仅 $L_f$+骨干）。
- 干预影响分析：用 ATE（Average Treatment Effect）量化 baseline/互补/随机/IR 丢弃/VI 丢弃的影响。
- 下游：目标检测、语义分割。
- 跨域：医学图像融合。
- 补充材料：超参数分析（掩码尺寸等）。

## 五、实验数量与充分性

- **规模**：覆盖 3 个 IVIF benchmark + 1 个 MIF 数据集 + 2 个下游任务（检测/分割）+ 5 组消融 + ATE 干预分析 + 超参数分析，实验组数量较多，横向覆盖较广（低层融合指标、高层语义任务、跨传感器零样本迁移）。
- **较充分的方面**：
  - 对比对象含 9 个近年 SOTA（含 2024–2025 年方法），并同时报告 5 类互补指标，避免了单一指标的片面性。
  - 消融逐项拆解 CFI、$L_{inv}$、$L_{nec}$ 与整体干预机制，因果关系较清晰。
  - 引入 ATE 量化不同干预的效应，为"干预确实在起作用"提供了直接证据（模态丢弃退化最大、随机掩码影响最小、互补掩码居中），与设计假设自洽。
  - 零样本 IVIF→MIF 迁移实验是较强的泛化性证据。
- **客观性与公平性上的保留**：
  - 文中未明确说明基线方法是使用官方预训练权重还是统一重训练、训练配置是否对齐，公平性存在不确定性。
  - 未报告多次运行的均值/方差或显著性检验，指标差异（如 Qabf 上 0.512 vs 0.510）难以判断是否显著。
  - 医学融合仅 20 对图像，样本量偏小，统计效力有限。
  - 部分指标并非全面领先（见下节），而摘要与结论的表述偏"全面 SOTA"，存在一定选择性陈述风险。
  - 下游任务仅各用单一网络（YOLOv5、官方分割网络），未做检测器/分割器的多样性验证。

## 六、主要结论与发现

- **IVIF 定量**：在 TNO、MSRS、M³FD 上 AG、SF、CC 均取得最优，PSNR 在 TNO（62.06）与 MSRS（66.02）最优；但 **Qabf 在 TNO 与 MSRS 上并非最高**（MSRS 上 0.545 低于 DCEvo 0.620、LUT-Fuse 0.579；TNO 上 0.423 低于 DCEvo 0.447），M³FD 上 PSNR（62.13）也低于 LRRNet（62.95）。总体上呈"结构/纹理类指标强、部分保真类指标有取舍"的格局。

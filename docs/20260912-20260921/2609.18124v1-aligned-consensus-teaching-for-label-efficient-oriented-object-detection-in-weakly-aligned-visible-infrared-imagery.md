## 摘要
可见光-红外目标检测（VIOD）从成对的可见光与红外图像中检测带有有向边界框的目标。现有方法依赖于代价高昂的双模态标注。半监督学习可以减轻这一负担，但将其从单模态检测扩展到 VIOD 具有挑战性。在本文考虑的实际图像对级设置中，只有少量图像对在两个模态中均被标注，其余图像对则完全未标注。这种有限的监督带来三个挑战：(i) 标注框过少，难以实现稳健的跨模态对齐；(ii) 由各分支漏检引起的伪标签错误在自训练过程中不断累积；(iii) 随着标注预算减少，尾部类别的标注变得极其稀缺。我们提出对齐共识教师（Aligned Consensus Teacher，ACT），用于该设置下的标签高效 VIOD。其循环一致区域对齐（Cycle-Consistent Region Alignment，CRA）通过可靠性加权的区域匹配将循环一致性与稀疏锚点相结合。跨模态共识均值教师（Cross-Modal Consensus Mean-Teacher，CMC-MT）在保持配对关系的视图下形成共识伪标签，以恢复各分支漏检并监督未标注图像对。文本引导的跨模态实例增强（Text-Guided Cross-Modal Instance Augmentation，TG-CMIA）利用视觉-语言场景先验来合成尾部类别实例对，同时保留 RGB-IR 偏移。据我们所知，ACT 是首个在该图像对级设置下研究半监督 VIOD 的框架。在 DroneVehicle 和 VEDAI 上的实验表明，在不同标注比例下均取得了一致的性能提升。在 DroneVehicle 上使用 10% 标注图像对时，ACT 达到了同一检测器在全监督下所获 mAP 的 94.3%。代码和模型将在 GitHub 上公开，以促进未来研究。

## Abstract
Visible-infrared object detection (VIOD) detects objects with oriented bounding boxes from paired visible and infrared images. Existing methods depend on costly dual-modality annotations. Semi-supervised learning can reduce this burden, but extending it from single-modal detection to VIOD is challenging. In the practical image-pair-level setting considered here, only a few pairs are labeled in both modalities, while the rest are completely unlabeled. This limited supervision creates three challenges: (i) too few labeled boxes for robust cross-modal alignment; (ii) pseudo-label errors caused by branch-wise misses accumulate during self-training; and (iii) tail-class annotations become critically scarce as the labeling budget decreases. We propose Aligned Consensus Teacher (ACT) for label-efficient VIOD in this setting. Its Cycle-Consistent Region Alignment (CRA) combines cycle consistency and sparse anchors with reliability-weighted regional matching. Cross-Modal Consensus Mean-Teacher (CMC-MT) forms consensus pseudo labels under pair-preserving views to recover branch-wise misses and supervise unlabeled pairs. Text-Guided Cross-Modal Instance Augmentation (TG-CMIA) uses a vision-language scene prior to compose tail-class instance pairs while preserving RGB--IR offsets. To the best of our knowledge, ACT is the first framework to study semi-supervised VIOD under this image-pair-level setting. Experiments on DroneVehicle and VEDAI show consistent gains across annotation ratios. With 10\% labeled pairs on DroneVehicle, ACT reaches 94.3\% of the mAP obtained by the same detector under full supervision. Code and models will be available on GitHub to facilitate future work.

- **本文设定（关键新设定）**：**图像对级半监督 VIOD**——少量图像对在 RGB 与 IR **两个模态上均被标注**，其余图像对**完全无标注**。作者称 ACT 是首个研究该设定的框架。
- **三大挑战**（由有限配对监督引出）：
  - **(i) 跨模态对齐监督不足**：两传感器视场与成像时间不同，同一目标存在固有位置/尺度偏差；仅标注对提供匹配框。DroneVehicle 上标注预算从全量降至 1%，匹配框由 286.8k 降至 3.2k（约 90× 减少）。
  - **(ii) 伪标签噪声累积**：RGB 与 IR 可见性差异导致**分支级漏检**（10% 预算下 RGB 召回 73.2% vs IR 91.1%），产生不完整伪标签，经 EMA 自训练误差循环放大。
  - **(iii) 尾部类别标注稀缺**：航空车辆呈长尾分布，标注子集收缩时尾部实例绝对数量骤降，尾部类 AP 下降远大于 Car。

## 2. 方法论：ACT（Aligned Consensus Teacher）

**核心思想**：以"区域级对齐正则 + 跨模态共识伪标签 + 保偏移尾部实例合成"三件套，在极少配对标注下实现标签高效半监督有向检测。

### 2.1 CRA：循环一致区域对齐（Cycle-Consistent Region Alignment）
- **稀疏锚点 + 循环一致**：设 RGB/IR 特征 $f_R, f_T$，区域 $b=(cx,cy,w,h,\theta)$，用 RoI-Align 取区域特征 $r_m(b)$。轻量前向头 $T_\psi$ 从双模态区域特征预测中心与尺度偏移，反向头 $T_{\psi'}$ 将变换后区域映回 RGB 帧，构成往返：
  - $b^{R\to T}=T(b,\Delta_b^{R\to T})$，$b^{R\to T\to R}=T(b^{R\to T}, T_{\psi'}([\cdot]))$；$T$ 只调整中心与尺度，**保持朝向不变**。
- **损失设计**：
  - $L_{cyc}$：对 RGB GT 区域集合 $\mathcal{R}$ 施加往返一致性，**无需为每个源区域匹配 IR 框（target-free）**。
  - $L_{align}$：在类一致匹配集 $\mathcal{A}$ 上用 Smooth-L1 回归编码后的真实偏移 $\Delta_b^*$；用于**消除循环一致本身允许的"互为一致但错误"映射**，防止变换漂移。
- **可靠性加权区域匹配**：区域置信度 $\omega_b=\mathrm{clip}(\omega^{vis}_b[1+\lambda_G(G_b-0.5)],0,1)$，其中 $\omega^{vis}_b=\sigma(\cos(z^b_R, z^{bR\to T}_T))$，$G_b$ 为离线场景先验给出的粗略占用分；$L_{cma}$ 为按 $\omega_b$ 加权的余弦失配。**权重用于抑制不确定对应信号，而非直接缩放融合特征**。
- **平滑约束** $L_{smooth}$：限制半径 $r_s$ 内相邻源区域偏移突变。
- **总目标**：$L_{CRA}=\lambda_a L_{align}+\lambda_c L_{cyc}+\lambda_m L_{cma}+\lambda_s L_{smooth}$，权重 $(1.0,0.5,0.5,0.3)$，$\lambda_G=0.3$；稀疏锚点要求跨模态 IoU ≥ 0.5，$r_s=64$ 像素。
- **不增加推理分支**，仅正则化融合表征，为 CMC-MT 的共识提供基础。

### 2.2 CMC-MT：跨模态共识均值教师
- **保配对师生视图**：对每个未标注对 $(I_R,I_T)$，两模态**共享同一几何变换 $H$**，各自施加模态专属光度算子生成弱/强视图：$I^v_m=P^v_m(H(I_m))$。由此师生视图内 RGB–IR 几何关系保持一致，教师框对学生视图仍然有效（避免单模态独立变换造成的坐标不一致）。
- **共识监督**：EMA 教师处理弱视图，经 CRA 正则化的**融合分支**聚合 RGB 与 IR 证据，输出 $P^w_{con}=D_{\bar\theta}(\Phi_{\bar\theta}(I^w_R,I^w_T))$，按置信度 $\tau$ 过滤得到 $\tilde{B}_{con}$。融合预测能在单分支漏检时保留目标证据，故共识标签比任一分支更完整。
- **训练流程**：短暂 burn-in（2,000 迭代）后以强视图监督学生，权重 $\lambda_u=1.0$；教师按 EMA（动量 0.999）随学生更新，形成闭环。

### 2.3 TG-CMIA：文本引导跨模态实例增强
- **共识引导尾部实例采样**：从标注对构建实例库 $\mathcal{B}$，仅保留类别一致且中心距离小于 $\tau_d \max(w,h)$（$\tau_d=0.6$）的 RGB–IR 裁剪对，类别限定 $C_{tail}=\{\text{truck, freight car, van}\}$；库中保存配对裁剪、有向框与**天然相对偏移**。
- **反频率采样**：$P(\iota_i)\propto n_{c_i}^{-1}$，提高最稀有类采样概率，不改变原标签。
- **场景感知、保偏移合成**：冻结的 **Qwen2.5-VL-32B** 一次性生成场景先验 $S=(G,d,\rho)$（2×2 占用网格、昼夜描述子、两模态可靠性），**不使用标注输入**。$G$ 选择合成单元，$d$ 允许夜间额外插入一对，$\rho$ 缩放模态专属羽化掩码。
- **关键约束**：对选中实例对施加**同一平移 $t$**：$p'_R=p_R+t,\ p'_T=p_T+t$，故 $p'_T-p'_R=p_T-p_R$，**原始跨模态位移被保留**，相对尺度与朝向不变，变换后框同时追加到两个标注集。
- **合成预算**：以 0.8 概率加入 1–4 对目标类实例，夜间至多额外 1 对。

### 2.4 总体目标与推理
- $L_{ACT}=L^l_{det}(D_l^+)+\lambda_u L^u_{det}(\tilde{B}_{con})+L_{CRA}$，其中 $D_l^+$ 为 TG-CMIA 增强后的标注集。
- **推理时仅保留融合 EMA 教师与有向检测头**，训练期模块全部丢弃。

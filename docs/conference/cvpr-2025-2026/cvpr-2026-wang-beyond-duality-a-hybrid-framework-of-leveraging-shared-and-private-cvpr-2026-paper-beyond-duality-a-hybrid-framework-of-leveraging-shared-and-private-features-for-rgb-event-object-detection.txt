# Abstract 

RGB-Event object detection is able to capture clear and de-tailed features of the target while maintaining high-speed information collection. It is suitable for high dynamic or harsh environments and has become a research hotspot in recent years. The existing RGB-Event object detectors all struggle to fully utilize the fusion features of two modal-ities, but do not explicitly disentangle shared vs. private features to dedicated branches. To fully tap into the po-tential of single features, we propose a frequency-domain coherence-based Shared and Private Features Decoupling method for RGB-Event object detection, SPFD network. First, we design a FCFS module to separate shared and private features by exploring the spectral energy distribu-tion differences between dual modalities. Then, we de-sign a TriAdapt Encoder to process the shared and pri-vate features, selectively emphasizing texture-rich RGB fea-tures in static regions and motion-sensitive event features in dynamic regions, thereby achieving a robust balance be-tween spatial detail and temporal awareness. Finally, a TriInject Decoder is proposed to emphasize the most dis-criminative modality features dynamically. Experimental results on the DSEC-Det and PKU-DAVIS-SOD datasets demonstrate that our model achieves competitive perfor-mance with state-of-the-art methods. Our codes are avail-able at https://github.com/git-KeYw/SPFD .

The key challenge in RGB-Event object detection lies in exploiting information from both modalities effectively and appropriately. Early multimodal detection frameworks [7, 15, 36, 44] typically adopt simple features concatenation, entire features interaction or post-processing strategies to fuse event and RGB modalities. Although these early ap-proaches achieve accuracy improvements, the fusion pro-cess remains superficial and does not explore the deep-level information of each modality. For ex-ample, in low-light scenarios where the RGB camera fails to perceive objects, event cameras can still capture motion information, which we define as the Event-private features. Conversely, when objects are relatively static with respect to the camera (e.g., vehicles moving at the same veloc-ity as the ego vehicle), the Event stream produces few re-sponses, and only the RGB modality can capture such in-formation—defined as the RGB-private features. For this specific scenario, simply fusing the two modalities is insuf-ficient to harness the distinctive strengths of each individ-ual modality. To fully tap into private features, we conduct analysis on bimodal modality and separate them into private features (RGB-private and Event-private) and shared fea-tures (overlapping section between two modality features). As shown in Fig. 1(b), our method reorganizes shared and modality-private features based on data characteristics and apply them in the encoder and decoder, instead of undif-ferentiated fusion like existing methods(Fig. 1(a)), in the setting of frame-based RGB–Event detectors that perform feature-level fusion. In this paper, we propose a frequency-domain coherence-based Shared and Private Features Decou-pling method for RGB-Event object detection, SPFD network. The SPFD network separates private features and shared features in the frequency domain (Frequency-domain Coherence-based Feature Separation module, FCFS), and applies above private features and shared features in both encoder (TriAdapt Encoder) and decoder (TriInject Decoder) appropriately. Specifically, the FCFS module adopts the Fourier transform on the RGB features and event features to project them into the frequency domain, respectively. And the FCFS module leverages spectral coherence to derive shared and private features. Then, the TriAdapt Encoder selects the most informative modality features in each spatial location and fuses the shared features and private features, to provide accurate memories for subsequent decoder adaptively. Finally, both the private features and the memories are passed into the TriInject Decoder, where layer-wise asymmetric private feature injection is applied to boost the final detection accuracy, especially for the positioning accuracy of bounding boxes. Experimental results on the DSEC-Det [13] and PKU-DAVIS-SOD [18] datasets demonstrate that our model achieves competitive performance with state-of-the-art methods. In summary, our contributions are as follows: 1. A SPFD network is designed for RGB-Event object de-tection, which explicitly leverage shared and private fea-tures, achieving satisfactory results in challenging sce-narios. 2. A frequency-domain disentanglement module is pro-posed to separate shared and private features between RGB and Event modalities. 3. A TriAdapt Encoder interacts with shared and private features adaptively, which is designed to provide repre-sentative features for the decoder. 4. A TriInject Decoder is proposed to boost detection accu-racy by injecting dual-modality private features in each decoder layer for precise adjustments. 

# 2. Related Work 

2.1. Transformer-based Object Detection 

The original DETR [5] introduces an end-to-end framework for object detection, employing the Transformer architec-ture for the first time in this task and achieving a unified pre-diction and bipartite matching mechanism. However, it suf-fers from slow convergence and inefficient feature utiliza-tion during training. To address these limitations, a series of works [20, 24, 41] have improved its defects. Deformable-DETR [45] introduces sparse multi-scale deformable atten-tion to enhance sampling efficiency and accelerate conver-gence. Building upon these works, MI-DETR [28] im-proves DETR with parallel multi-queries and U-shaped fea-ture interaction, but it remains single-modal and lacks ex-plicit cross-modal modeling for multimodal detection. 

2.2. RGB-Event Fusion Framework 

The core challenge in fusing Event and RGB modalities lies in effectively extracting and exploiting their complemen-tary information. Feature-level fusion strategies have been widely adopted to leverage the strengths of both modalities. FPN-Fusion [36] performs multi-level feature aggregation by connecting fused representations across layers. SOD-Former [18] introduces a self-attention-based adaptive fu-sion mechanism. SFNet [25] restores missing information through cross-modal global spatial similarity computation, while CAFR [3] progressively fuses multi-modal features from coarse to fine via a cross-attention mechanism. In or-der to produce better fused features, some work [14, 21, 35] has also brought new ideas to the RGB-Event fusion. How-ever, most existing methods adopt uniform processing for low-information regions of both modalities, which leads to redundant computation and an overemphasis on shared features, thereby weakening the exploitation of modality-specific characteristics.

In visual tasks, frequency-domain features have been ex-tensively applied in image enhancement, reconstruction and detection. For instance, FcaNet [32] introduces a multi-frequency attention module within feature channels to ex-plicitly model the importance of different frequency bands, thereby enhancing the representational capacity of convo-lutional networks. In the field of object detection, several studies leverage the energy distribution in the frequency domain to enhance feature discriminability. For example, HiLo Transformer [29] strengthens fine-grained edge rep-resentation via high–low frequency separation, effectively improving small-object detection performance. In multimodal visual tasks, the value of frequency-domain modeling becomes even more significant [31, 37, 43]. Re-cently, learnable spectral filtering strategies have also emerged, including models such as Spectral Attention Fu-sion [17] and FreqFormer [8], which employ trainable band-pass filters or spectral attention matrices to adaptively sup-press modality discrepancies. However, no prior work has deeply analyzed the relationship between the private fea-tures and the shared features between modalities. 

# 3. Method 

3.1. Overall Framework 

Given an RGB image I ∈ RW ×H×3 and its corresponding event image E ∈ RW ×H×3, the proposed SPFD network aims to generate the bounding boxes Bi(xi, y i, w i, h i)Ki=1 

and the corresponding category labels {Ci}Ki=1 of K ob-jects. As illustrated in Fig. 2, the overall framework follows the DETR-style architecture and consists of three key com-ponents: the Frequency-domain Coherence-based Feature Separation module (FCFS), the TriAdapt Encoder and the TriInject Decoder. We use backbone network to extract the event features x and the RGB features y, respectively. The FCFS module transforms x, y into the frequency domain 

X, Y , where private energy components are selectively en-hanced according to their spectral characteristics. The mod-ule then disentangles shared features Zs between modalities and private features ( Zr and Ze) for subsequent process-ing. Afterward, the three feature streams are fed into the TriAdapt Encoder, which leverages the shared representa-4417 tion to guide the private branches, forming a semantically consistent yet modality-complementary memory represen-tation. Finally, the TriInject Decoder receives the multi-level memory features and injects private information into each decoding layer, adaptively controlling the contribu-tions of RGB and event features across different semantic depths.

Un-like traditional spatial convolution or attention-based mech-anisms, the FCFS module operates in the frequency domain and utilizes spectral statistics to characterize the semantic correlation and uniqueness between modalities by analyz-ing the coherence of spectral energy [1]. As shown in Fig. 3, the entire process consists of three stages: spectrum statis-tics, coefficient calculations and feature separation. 3.3. TriAdapt Encoder 

In Transformer-style detectors, the encoder provides high-quality location-aware features rich in global contextual in-formation. For RGB-Event bimodal object detection task, how to effectively utilize the shared features and private fea-tures is critical for the prediction results. To achieve adap-tive selection and robust balancing between two private fea-tures, we propose TriAdapt Encoder. As shown in Fig. 4, the TriAdapt Encoder employs multi-scale Deformable At-tention [45] and a learnable Gating Mechanism to guide the interaction between two private features and update new fused memory. Specifically, the TriAdapt Encoder tends to rely more on RGB features in regions with rich textures, while in highly dynamic regions it favors Event-based fea-tures that capture motion information. # 4. Experiments 

4.1. Datasets and Metrics 

Datasets. We conduct a series of experiments on two public datasets, DSEC-Det [13] and PKU-DAVIS-SOD [18]. The DSEC-Det [13] dataset is a multimodal bench-mark extending the original DSEC with synchronized RGB–Event data and object detection annotations for eight traffic categories, supporting the training and evaluation of multimodal detection models. It has RGB images at 1440×1080 and Event data at 640×480, and contains eight categories. The DSEC-Det dataset provides multiple anno-tation versions. Our ablation studies are conducted on the original annotations, while for fair comparison with prior works, we adopt the SFNet [25] annotation version in the comparative experiments. The PKU-DAVIS-SOD [18] dataset is collected using a DAVIS346 event camera and provides spatially aligned RGB frames and event streams at a resolution of 346 ×

260 . It contains over 870k manually annotated bounding boxes for three object categories—car, pedestrian and cy-clist—captured under normal, motion-blur and low-light conditions. 

Metrics. We adopt the standard COCO evaluation protocol for object detection. The primary metrics are mAP, mAP 50 ,and mAP 75 .

4.2. Implementation Details 

Experiments are conducted on two NVIDIA RTX 4090 GPUs with a batch size of 4 per GPU. We use ResNet-50 as the backbone and train for 100k iterations with an initial learning rate of 1×10 −4, which is decayed by a factor of 10 at 80k iterations. We set ε = 10 −6, τ = 0 .25 , and T = 0 .2.RGB inputs are the original three-channel frames. Event streams are converted to three-channel frames by accumu-lating events within each frame interval, where the chan-nels represent positive polarity, negative polarity, and their sum. Data augmentation includes multi-scale training and random horizontal flipping. 

4.3. Comparison with State-of-the-Art methods 

We compare our method with recent state-of-the-arts ap-proaches on DSEC-Det and PKU-DAVIS-SOD datasets, re-spectively. We list mAP and mAP 50 of Event-based, RGB-based and RGB–Event multimodal detectors on these two public datasets. As illustrated in Tab. 1, Among all meth-ods, our SPFD network achieves 34.6% mAP on DSEC-Det [13] and 32.0% mAP on PKU-DAVIS-SOD [18]. On the two datasets, our method surpasses the SOTA by 4.2% and 0.1% in mAP, and by 5.3% and 2.8% in mAP 50 , respec-tively. The comparison results demonstrate that our SPFD network outperforms existing methods and achieves state-of-the-art. 

4.4. Ablation Study 

We conduct a series of ablations on DSEC-Det test set to quantify each module. As illustrated in Tab. 2, we extend single-modal detector MI-DETR [28] to the multimodal (using a linear projection to concatenate RGB and event features) as baseline model (row #1). Adding FCFS module and using only shared features yields +0.6% mAP (row #2). Injecting private features through the proposed TriAdapt en-coder further provides +1.1% mAP (row #3). Finally, when we use FCFS module, TriAdapt Encoder and TriInject De-coder at the same time, the mAP reaches 49.2% (row #4).

# 5. Limitations. 

SPFD, like prior RGB-Event methods, may struggle when both modalities are severely degraded, such as under low-contrast APS imaging, noisy event streams, or strong mo-tion blur. In these cases, cross-modal coherence estimation becomes less reliable, which can weaken the shared-private separation and reduce detection accuracy. Future work will focus on improving the robustness of coherence estimation. 

# 6. Conclusions. 

In this paper, we propose SPFD, an RGB–Event multi-modal detection architecture that disentangles shared and modality-private features based on data characteristics and applies them in both the encoder and decoder. SPFD achieves state-of-the-art performance on DSEC-Det and PKU-DAVIS-SOD.
